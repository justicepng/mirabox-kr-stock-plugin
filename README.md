# Mirabox Stream Dock - 국내/해외 주식·선물·매크로 플러그인 (v1.3.0)

Mirabox Stream Dock(15키 메인 버튼 및 293S 우측 세로 스크린 `Information` / `SecondaryScreen`)에 국내·해외 주식, ETF, 지수, 선물, 환율, 원자재, 채권 금리 등 매크로 지표를 실시간으로 표시하고, 버튼을 누르면 **네이버페이 증권**(또는 Yahoo Finance) 화면으로 이동하는 플러그인입니다.

## 주요 기능
- **국내 주식/ETF/지수**: 코스피(`KOSPI`), 코스닥(`KOSDAQ`), 코스피200(`KPI200`), 국내 개별 종목 및 ETF 검색/표시
- **해외 지수 및 선물**: 나스닥100/S&P500/다우/러셀2000 선물, 나스닥 종합, S&P 500, 필라델피아 반도체 등
- **매크로 지표**: WTI 원유, 브렌트유, 천연가스, 국제 금/은/구리, 미 10년/30년 국채금리, 달러인덱스, 환율(USD/KRW, USD/JPY, EUR/USD), VIX, 비트코인
- **원클릭 브라우징**: 버튼 클릭 시 네이버페이 증권(`stock.naver.com`) 또는 해당 지표 상세 페이지 오픈
- **293S 우측 세로 스크린 지원**: `Keypad`, `Information`, `SecondaryScreen` 모두 지원

## 설치 방법
1. 저장소를 클론하거나 릴리스 압축 파일을 다운로드합니다.
2. `설치하기.bat`를 실행합니다. (`%APPDATA%\HotSpot\StreamDock\plugins\com.krstock.streamdock.sdPlugin`에 설치 및 로컬 릴레이 등록)
3. Mirabox Stream Dock을 완전히 종료 후 재실행합니다.
