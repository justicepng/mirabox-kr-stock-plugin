[설치 방법]
1. 압축 파일의 압축을 원하는 폴더에 풉니다.
2. 압축을 푼 폴더 안의 "설치하기.bat" 파일을 더블 클릭하여 실행합니다.
   (폴더명: com.krstock.streamdock.sdPlugin — 기존 버튼 설정은 그대로 유지됩니다)
3. "Local realtime relay (v1.3.0) is RUNNING on http://127.0.0.1:18765" 메시지를 확인한 뒤 창을 닫습니다.
4. Mirabox Stream Dock 프로그램을 완전히 종료(트레이 아이콘 우클릭 -> 종료)한 뒤 다시 실행합니다.

[293S 우측 스크린 배치 방법]
- Stream Dock 화면에서 [국내/해외 주식 시세] 액션을 일반 버튼뿐 아니라 가장 우측 세로 스크린 슬롯(3칸)에도 그대로 드래그해 배치할 수 있습니다.
